# 1. PROJECT OVERVIEW

The Hotel Booking & Cancellation Analysis project focuses on analysing hotel booking data to understand booking patterns, customer behaviour, cancellation trends and hotel pricing.

The project uses data from two types of hotels: City Hotel and Resort Hotel.

The analysis is performed using Python for data cleaning and preparation, SQL for querying and analysing data, and Power BI for creating an interactive dashboard.

The main objective is to transform raw booking data into meaningful insights that can help hotels understand their booking performance and cancellation behaviour.

# 2. BUSINESS PROBLEM

Hotels receive bookings from different customers through various market segments and booking channels. However, cancellations can affect booking performance, room availability and business planning.

Understanding booking trends and cancellation patterns is important for improving hotel operations and making better business decisions.

This project aims to answer important business questions such as:

- What is the total number of hotel bookings?
- How many bookings were canceled?
- What is the overall cancellation rate?
- Which hotel type receives more bookings?
- How do booking trends change over time?
- Which lead-time groups have higher cancellation rates?
- How do new and repeat guests behave?
- Which countries contribute the most bookings?
- How does the average daily rate change over time?
- How do cancellation patterns differ across market segments?

### Feature Engineering

The following new columns were created:

**1. Arrival Date**

Combined the arrival year, month and day information into a single date column.

**2. Arrival Month**

Created a month column to analyse monthly booking trends.

**3. Arrival Year**

Created a year column to compare booking performance across years.

**4. Total Guests**

Calculated the total number of guests using adults, children and babies.

**5. Total Nights**

Calculated the total length of stay using weekend nights and weekday nights.

**6. Weekend Stay**

Created a column to identify bookings that included weekend stays.

**7. Family Booking**

Created a column to identify bookings with children or babies.

**8. Booking Status**

Created a column to identify whether a booking was canceled or not canceled.

**9. Lead Time Group**

Grouped bookings according to their lead time to analyse cancellation behaviour.

**10. Estimated Booking Value**

Calculated estimated booking value using:

Estimated Booking Value = ADR × Total Nights

This is an estimated booking value and should not be treated as actual revenue collected.
